Getting Started

Add beautiful view count badges or SVG banners to your GitHub repositories in just a few simple steps:

1
Choose your preferred style

Browse our collection of professionally designed badges and banners, then select the one that matches your repository's aesthetic.

2
Copy the markdown code

Copy the provided markdown code for your selected badge or banner style.

3
Add to your repository README

Paste the code into your README.md file and commit the changes.

4
Watch your views or showcase your profile

API Reference

Our robust API allows for seamless integration and customization:

Update View Count

To manually update view counts, send a POST request to:

/update_views/{repository-tag}

Parameters

Parameter Type Description
repository-tag String Your unique repository identifier

Technical Notes

  • View counts are updated in real-time with minimal latency
  • Statistics are calculated based on the last 30 days of repository activity
  • All badges and banners are responsive and automatically adapt to both light and dark GitHub themes
  • SVGs are intelligently cached for optimal performance and reduced server load
  • Badges and banners are lightweight and won't impact your repository's load time
Pro Tip: For the most accurate tracking, use your exact repository name as the tag parameter when implementing badges. For banners, replace 'IshanOshada' with your own username or text.
